1

Minh-Long Pham, Ching-Chun Huang

TRACE: Truthfulness Regulated Alignment through Corrected Estimation

In progress
  • Problem — Training-free alignment such as OPAD follows a user-defined system prompt, but reshaping the output distribution causes hallucination and over-steering.
  • Approach — Entropy-aware token selection against hallucination and Dynamic Rejection against over-steering, without fine-tuning the base model.
2

Minh-Long Pham, Ching-Chun Huang

TAMiOS: Transformer-embedded Agentic Multi-agent System for iOS

In progress
  • Problem — Agentic frameworks assume server-side orchestration; on-device, every planning, routing and tool-calling step competes for the same NPU and memory budget.
  • Approach — On-device planner with specialist agents over MLX, native tools (speech, location, camera), and a memory- and thermal-aware scheduler, fully local.
3

Minh-Tu Cao*, Khanh-Nhan Tran*, Minh-Long Pham

RAILIGHT: A Robust Illumination-Adaptive Framework for Railway Defect Detection

In progress
  • Problem — Railway inspection runs largely at night, but detectors trained on labelled daytime imagery degrade sharply on night footage, and re-annotating night data is costly.
  • Approach — Unsupervised domain adaptation from labelled day to unlabelled night footage, with no night labels: 0.72 mAP@50 on real night footage, +0.20 over the daytime-only baseline.
